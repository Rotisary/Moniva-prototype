# Moniva

An interactive hackathon prototype for social commerce intelligence and financial
inclusion. Moniva turns a Nigerian SME's WhatsApp and Instagram selling activity
into structured business records, reconciled payments, and a merchant financial
profile that the merchant can share with financial institutions, with consent.

All data is seeded mock data stored in the browser. Social-platform, bank, and
data-sharing integrations are simulated.

## Commands

- Dev server: `npm run dev` (http://localhost:5173)
- Build: `npm run build`
- Preview production build: `npm run preview`
- Lint: `npm run lint`
